# Profacciata + Higgsfield Workflow

Use this skill when producing visual assets for the Profacciata website through the connected, official Higgsfield MCP tools.

## Project identity

Profacciata is the contractor/applicator that executes interior and exterior surface-coating projects. Suppliers such as Luxture and other manufacturers provide materials, products, and finish systems.

Creative direction: luxury architecture + modern digital design + professional construction-industry trust.

Starting palette (confirm against the actual company logo before finalizing):
- Warm ivory: `#F5F2EC`
- Architectural charcoal: `#242725`
- Copper clay: `#B96F4A`
- Concrete beige: `#D6CFC2`
- Muted sage: `#657466`

## Brand and project accuracy rules

- Preserve the original Profacciata logo. Do not regenerate, redraw, restyle, or alter its spelling or tagline with an image model. Place the supplied original logo separately in page layouts.
- Supplier catalogue images are references for materials and product lines. Do not claim that Profacciata manufactures supplier products or holds an exclusive partnership unless confirmed.
- Never present an AI-generated concept render, stock image, supplier catalogue image, or unrelated online photo as a completed Profacciata project.
- Conceptual imagery should be labeled internally as a concept/reference until the company approves it for public display.
- Do not add fake logos, customer testimonials, certification badges, warranty claims, product specifications, or text embedded in generated images.
- For named projects, do not create an image that appears to document Profacciata's work. Generate only conceptual architectural mood imagery unless genuine project photos have been supplied and verified.

## Credit and approval safeguards

- Before a generation, check remaining Higgsfield balance/credits when the connected tools expose a balance-check operation.
- Image/video generations through MCP may deduct standard credits even when the web subscription has unlimited or free-generation entitlements. Do not assume MCP generations are free.
- Before generating a video, a high-resolution output, or multiple variants, explain that credits may be charged and ask for approval if the user has not already approved that scope.
- Prefer one low-cost still-image concept first. Generate only 1–2 variants until a direction is approved.
- Never loop generations or automatically create large batches without explicit user approval.

## Recommended workflow

1. Read the current user request and identify the output: direction board, hero still, surface detail, storyboard, or video.
2. If a brand or material reference is relevant, ask the user to attach or select the actual supplied reference. Do not pretend an unavailable file has been attached to the tool call.
3. Check credits where supported and confirm any material spend before costly generation.
4. Generate a small initial set. Use 16:9 landscape for website hero/reference boards unless another size is requested.
5. Keep generated image text-free; page text and original logo should be added in code/design tools for fidelity.
6. Report which outputs are conceptual and state the suggested filename and intended use.
7. If returned media cannot be written directly to the workspace, provide the result URL and tell the user to download it into the project's asset folder. Do not claim local files exist unless created and verified.
